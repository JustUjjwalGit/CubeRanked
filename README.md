# CubeRanked

Competitive Rubik's Cube platform prototype.

This first slice establishes the frontend base and the 3x3 cube engine:

- React + TypeScript + Vite
- Tailwind CSS styling foundation
- React Three Fiber + Drei 3D cube scene
- Zustand cube state store
- Pure TypeScript 3x3 turn engine
- Unit tests for cube rotations
- Playwright scene verification for desktop and mobile

## Scripts

```bash
npm install
npm run dev
npm run build
npm test
npm run verify:e2e
```
